# Private-only sudo askpass helpers (not for the Vicinae store)

`vicinae-sudo-askpass`, `vicinae-sudo-password-warm`, and `vicinae-sudo-prompt`
are installed by `scripts/install-runner.sh` onto this machine so Topgrade and
package operations can prompt for sudo in a GUI.

Do not copy this directory into a `vicinaehq/extensions` pull request.
